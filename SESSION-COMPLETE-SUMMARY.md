## 🚀 HOW TO USE YOUR DESIGN SYSTEM

### **Update Colors:**
1. Open `/src/styles/theme.css`
2. Change color variables in `:root` section
3. Update `.dark` section for dark mode
4. Save → All 36 templates update instantly ✅

### **Update Typography:**
1. Open `/src/styles/theme.css`
2. Change font size variables (clamp values)
3. Save → All typography updates instantly ✅

### **Change Fonts:**
1. Open `/src/styles/fonts.css` → Replace font import
2. Open `/src/styles/theme.css` → Update font-family
3. Save → New fonts apply everywhere ✅

### **View Live Demo:**
