## 🎊 **MIGRATION PATTERNS ESTABLISHED**

### **WordPress Utilities (Most Common):**
```tsx
// Max-width containers
.wp-max-w-3xl    // 768px, centered
.wp-max-w-4xl    // 896px, centered
.wp-max-w-6xl    // 1152px, centered

// Responsive grids
.wp-grid-2-cols  // 1 col mobile → 2 cols desktop
.wp-grid-3-cols  // 1 col mobile → 2 tablet → 3 desktop

// Text alignment
.wp-text-center  // text-align: center
```

### **CSS Variables (All Tokens):**
```tsx
// Spacing
paddingTop: 'var(--spacing-16)'
gap: 'var(--spacing-8)'
marginBottom: 'var(--spacing-12)'

// Typography
fontSize: 'var(--text-h1)'
fontFamily: 'Lexend, sans-serif'
fontWeight: 'var(--font-weight-bold)'

// Colors
backgroundColor: 'var(--card)'
color: 'var(--foreground)'
borderColor: 'var(--border-soft)'

// Border Radius
borderRadius: 'var(--radius-lg)'
```

### **Inline Styles (Layout/Positioning):**

// Positioning
