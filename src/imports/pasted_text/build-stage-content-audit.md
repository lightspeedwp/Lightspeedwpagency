# **Services – Build Stage**

### **Summary**

* **Value** – Transforms polished designs into a secure, performant WordPress site. The build stage involves developing a custom block theme, integrating third‑party services, migrating content and hardening security – all with AI assistance.  
    
* **Risks** – Poor code quality or weak security can lead to technical debt, vulnerabilities and suboptimal performance. Without careful testing, migrations may fail or break existing integrations.  
    
* **Next step** – Update copy to explain how AI tools accelerate development, improve code quality and assist in testing. Showcase deliverables clearly and highlight the client’s role.

### **Content audit**

* **Hero messaging** – The page opens with **“Build. Develop. Integrate. Harden.”** and positions this stage as the point where designs become reality. It notes that a block theme is developed with modern patterns and security‑first architecture and quotes a typical duration of **4–8 weeks**[\[1\]](https://lightspeedwp.figma.site/services/build). Expand this messaging to emphasise AI‑assisted development, automated code generation and security scanning.  
    
* **What happens during Build?** – The page explains that designers work with developers to turn designs into a real website using block themes, integrate third‑party services (CRM, analytics, payments), migrate content and stress‑test the site under real conditions[\[2\]](https://lightspeedwp.figma.site/services/build). Highlight how AI helps generate boilerplate code, auto‑optimises images and performs regression tests.  
    
* **Why it matters** – It emphasises clean code, performance and security for a maintainable site[\[2\]](https://lightspeedwp.figma.site/services/build). Expand to include AI quality assurance, such as continuous integration pipelines with AI code reviews and vulnerability scanning.  
    
* **Deliverables** – The deliverables listed include a fully functional WordPress block theme, custom Gutenberg patterns & blocks, third‑party integrations, content migration with zero data loss, security hardening & firewall configuration and a staging environment for client review[\[2\]](https://lightspeedwp.figma.site/services/build). Present these as a visual checklist or timeline. Add deliverables like **AI‑assisted performance tuning** and **automated accessibility testing results**.  
    
* **What you’ll receive** – The site lists a custom block theme with FSE support, plus notes on client responsibilities such as testing the staging site, entering content, providing API keys and participating in weekly check‑ins[\[3\]](https://lightspeedwp.figma.site/services/build). Clarify that clients will receive access to staging with analytics dashboards and that they should supply API keys for any AI services.  
    
* **Testimonials and CTA** – A testimonial describes a seamless migration and strong support[\[4\]](https://lightspeedwp.figma.site/services/build). The CTA “Ready to Build” invites users to start development[\[5\]](https://lightspeedwp.figma.site/services/build). Update this CTA to emphasise AI‑assisted development and quality assurance.

### **WebGL hero & interactive ideas**

* **Hero concept** – Represent building as a dynamic 3D blueprint. Use WebGL to display a wireframe of a house or building morphing into a finished structure, with code lines flowing along the beams. Neon‑lime and neon‑cyan lines animate to show data flows and security layers. Hovering over elements reveals labels: “Block theme”, “API integration”, “Content migration”, etc.  
    
* **Code visualiser** – Embed a mini IDE visualiser that displays sample code generated by AI tools. The code auto‑types itself on screen, highlighting AI’s role in speeding up development. Users can click to expand into a full code example or watch a simulated code review.  
    
* **Migration progress tracker** – Include an interactive bar representing the migration process. As users scroll, the bar fills and triggers micro‑animations showing data moving from an old site to the new site.

### **Recommended actions**

1. **Refine copy** to stress AI‑powered development, automated testing, security scanning and continuous integration. Mention performance budgets and Core Web Vitals targets.  
     
2. **Visualise deliverables** via a checklist or timeline: block theme, custom patterns/blocks, integrations, migration, security hardening, staging environment.  
     
3. **Highlight the client’s role** clearly: provide content/API keys, test staging, give feedback. Offer a simple portal for uploading assets and tracking progress.  
     
4. **Replace static testimonials** with a carousel of case studies that showcase successful migrations, code quality and security improvements. Include metrics like reduced page load times.  
     
5. **CTA** – Encourage visitors to start an AI‑assisted build by requesting a development audit or scoping session. Use a button with dynamic hover effect (e.g., code brackets that animate when hovered).
