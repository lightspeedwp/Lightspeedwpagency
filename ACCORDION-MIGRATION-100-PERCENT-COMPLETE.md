### **What Changed**

**Before (Old Code):**
```tsx
// ❌ OLD: 90 lines of hardcoded accordion
<details style={{ padding: '24px', ... }}>
  <summary style={{ fontSize: 'var(--text-h4)', ... }}>
    {faq.question}
  </summary>
  <p style={{ fontSize: 'var(--text-base)', ... }}>
    {faq.answer}
  </p>
</details>
```

**After (New Code):**
```tsx
// ✅ NEW: 7 lines with WordPress component
import { FAQSection } from '../patterns/FAQSection';
import { servicesFAQs } from '../../data/faqs-extended';

<FAQSection faqs={servicesFAQs} />
```
