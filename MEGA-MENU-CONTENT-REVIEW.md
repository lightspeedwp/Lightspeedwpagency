✅ **Font Sizes:**
- `fontSize: 'var(--text-h4)'` — Mega menu titles
- `fontSize: 'var(--text-base)'` — Featured item titles, column headers, menu items
- `fontSize: 'var(--text-small)'` — Descriptions, meta text

✅ **Font Weights:**
- `fontWeight: 'var(--font-weight-bold)'` — Mega menu titles
- `fontWeight: 'var(--font-weight-semibold)'` — Featured titles, column headers, active nav
- `fontWeight: 'var(--font-weight-medium)'` — Menu item labels
- `fontWeight: 'var(--font-weight-regular)'` — Descriptions, inactive nav

✅ **Colors:**
- `color: 'var(--foreground)'` — Primary text
- `color: 'var(--muted-foreground)'` — Secondary text, descriptions
- `color: 'var(--primary)'` — Active/hover states
- `backgroundColor: 'var(--card)'` — Mega menu background
- `backgroundColor: 'var(--muted)'` — Hover states, image placeholders
- `border: '1px solid var(--border-soft)'` — Borders
