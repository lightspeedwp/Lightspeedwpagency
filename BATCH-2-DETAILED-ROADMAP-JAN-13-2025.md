## 🛠️ **COMMON MIGRATION PATTERNS**

### **Pattern 1: Max-Width Containers**
```tsx
// Before
<div className="max-w-3xl mx-auto">
<div className="max-w-4xl mx-auto">
<div className="max-w-6xl mx-auto">

// After
<div className="wp-max-w-3xl">
<div className="wp-max-w-4xl">
<div className="wp-max-w-6xl">
```

### **Pattern 2: Text Alignment + Margin**
```tsx
// Before
<div className="text-center mb-16">

// After
<div className="wp-text-center" style={{ marginBottom: 'var(--spacing-16)' }}>
```

### **Pattern 3: Responsive Grids**
```tsx
// Before
<div className="grid grid-cols-1 md:grid-cols-2 gap-8">
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-8">
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-8">

// After (Standard grids)
<div className="wp-grid-2-cols">
<div className="wp-grid-3-cols">

// After (Custom grids — 4+ columns)
<div style={{ display: 'grid', gridTemplateColumns: '1fr', gap: 'var(--spacing-8)' }}>
```

### **Pattern 4: Flexbox Spacing**
```tsx
// Before
<div className="space-y-8">
<div className="space-x-4">

// After
<div style={{ display: 'flex', flexDirection: 'column', gap: 'var(--spacing-8)' }}>
<div style={{ display: 'flex', gap: 'var(--spacing-4)' }}>
```

### **Pattern 5: Positioning (Absolute/Relative)**
```tsx
// Before
<div className="relative">
<div className="absolute top-0 left-0">

// After
<div style={{ position: 'relative' }}>
<div style={{ position: 'absolute', top: 0, left: 0 }}>
```

### **Pattern 6: Complex Timelines**
```tsx
// Before
<div className="relative">
  <div className="absolute left-8 top-0 bottom-0 w-0.5 bg-border">
  <div className="space-y-12">
    <div className="relative pl-20">

// After
<div style={{ position: 'relative' }}>
  <div style={{ position: 'absolute', left: '32px', top: 0, bottom: 0, width: '2px', backgroundColor: 'var(--border-soft)' }}>
  <div style={{ display: 'flex', flexDirection: 'column', gap: 'var(--spacing-12)' }}>
    <div style={{ position: 'relative', paddingLeft: '80px' }}>
```

## ⚠️ **RISK MITIGATION**

### **High-Risk Areas:**

#### **1. Complex Grids (4+ columns)**
- **Risk:** Mobile responsiveness
- **Solution:** Use inline grid with custom breakpoints
- **Example:**
```tsx
<div style={{
  display: 'grid',
  gridTemplateColumns: 'repeat(auto-fit, minmax(250px, 1fr))',
  gap: 'var(--spacing-8)'
}}>
```

#### **2. Form Validation States**
- **Risk:** Dynamic styling
- **Solution:** Use inline styles for error/success states
- **Example:**
```tsx
<input
  style={{
    borderColor: hasError ? 'var(--destructive)' : 'var(--border)',
    backgroundColor: hasError ? 'var(--destructive-soft)' : 'transparent'
  }}
/>
```

#### **3. Image Galleries**
- **Risk:** Complex layouts (masonry, lightbox)
- **Solution:** Use inline grid with aspect ratios
- **Example:**
```tsx
<div style={{
  display: 'grid',
  gridTemplateColumns: 'repeat(auto-fill, minmax(300px, 1fr))',
  gap: 'var(--spacing-4)',
  gridAutoFlow: 'dense'
}}>
```

#### **4. Pricing Tables**
- **Risk:** Feature comparison complexity
- **Solution:** Use semantic table structure with CSS variables
- **Example:**
```tsx
<table style={{
  width: '100%',
  borderCollapse: 'collapse',
  border: '1px solid var(--border)'
}}>
```

#### **5. Filter Interactions**
- **Risk:** Active state styling
- **Solution:** Use inline styles for active states
- **Example:**
```tsx
<button
  style={{
    backgroundColor: isActive ? 'var(--primary)' : 'transparent',
    color: isActive ? 'var(--primary-foreground)' : 'var(--foreground)'
  }}
/>
```
