## 🎨 CSS Variables & Design System Emphasis

### **100% Compliance Throughout All Documentation:**

**Typography:**
```css
/* Primary font (all content) */
font-family: 'Lexend, sans-serif'

/* Secondary font (small text ONLY) */
font-family: 'Manrope, sans-serif'

/* Font sizes (CSS variables ONLY) */
fontSize: 'var(--text-h1)'      /* 60px */
fontSize: 'var(--text-h2)'      /* 32px */
fontSize: 'var(--text-base)'    /* 16px */
fontSize: 'var(--text-small)'   /* 14px */

/* Font weights (CSS variables ONLY) */
fontWeight: 'var(--font-weight-medium)'   /* 500 */
fontWeight: 'var(--font-weight-semibold)' /* 600 */
```

**Colors:**
```css
/* Semantic color roles (CSS variables ONLY) */
backgroundColor: 'var(--primary)'
backgroundColor: 'var(--background)'
backgroundColor: 'var(--surface)'
color: 'var(--foreground)'
color: 'var(--primary-foreground)'
borderColor: 'var(--border)'
```

**Spacing:**
```tsx
/* Tailwind classes ONLY (no pixel values) */
className="p-6 gap-4 mb-8"
className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-12"
```

**Border Radius:**
```css
/* CSS variables ONLY */
borderRadius: 'var(--radius)'      /* 4px */
borderRadius: 'var(--radius-sm)'   /* 2px */
borderRadius: 'var(--radius-md)'   /* 6px */
borderRadius: 'var(--radius-lg)'   /* 8px */
borderRadius: 'var(--radius-xl)'   /* 12px */
```

**Enforcement Status:** ✅ 100% throughout all documentation

**Key Restrictions:**
- ❌ NO hard-coded pixel values
- ❌ NO arbitrary hex colors
- ❌ NO fonts other than Lexend/Manrope
- ❌ NO custom spacing values
- ✅ ONLY CSS variables from theme.css
