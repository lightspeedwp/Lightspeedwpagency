## 🛠️ **TOP 5 MIGRATION PATTERNS**

### **1. Max-Width Containers**
```tsx
className="max-w-4xl mx-auto" → className="wp-max-w-4xl"
```

### **2. Text Center + Margin**
```tsx
className="text-center mb-16" → className="wp-text-center" style={{ marginBottom: 'var(--spacing-16)' }}
```

### **3. Responsive Grids**
```tsx
className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-8" → className="wp-grid-3-cols"
```

### **4. Flexbox Spacing**
```tsx
className="space-y-8" → style={{ display: 'flex', flexDirection: 'column', gap: 'var(--spacing-8)' }}
```

### **5. Positioning**
```tsx
className="relative" → style={{ position: 'relative' }}
className="absolute top-0 left-0" → style={{ position: 'absolute', top: 0, left: 0 }}
```
