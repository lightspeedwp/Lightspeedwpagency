## 📦 WordPress Mapping

### Image Block → WordPress

**Core Block:** `core/image`

```html
<!-- wp:image {"sizeSlug":"large"} -->
<figure class="wp-block-image size-large">
  <img src="/photo.jpg" alt="Description" />
  <figcaption>Photo caption</figcaption>
</figure>
<!-- /wp:image -->
```

### Gallery Block → WordPress

**Core Block:** `core/gallery`

```html
<!-- wp:gallery {"columns":3} -->
<figure class="wp-block-gallery columns-3">
  <ul class="blocks-gallery-grid">
    <li class="blocks-gallery-item">
      <figure>
        <img src="/img1.jpg" alt="Image 1" />
      </figure>
    </li>
  </ul>
</figure>
<!-- /wp:gallery -->
```

### Cover Block → WordPress

**Core Block:** `core/cover`

```html
<!-- wp:cover {"url":"/hero.jpg","dimRatio":50} -->
<div class="wp-block-cover">
  <span class="wp-block-cover__background"></span>
  <div class="wp-block-cover__inner-container">
    <h1>Hero Title</h1>
  </div>
</div>
<!-- /wp:cover -->
```

### Video Block → WordPress

**Core Block:** `core/video`

```html
<!-- wp:video -->
<figure class="wp-block-video">
  <video controls src="/video.mp4"></video>
  <figcaption>Video caption</figcaption>
</figure>
<!-- /wp:video -->
```
