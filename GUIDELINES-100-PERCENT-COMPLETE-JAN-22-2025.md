## 🎓 GUIDELINES QUALITY STANDARDS

Every guideline enforces:

1. **CSS Variables ONLY**
   - Typography: `var(--font-primary)` or `var(--font-secondary)`
   - Spacing: `var(--spacing-*)`
   - Colors: `var(--foreground)`, `var(--primary)`, etc.
   - Radius: `var(--radius*)` 

2. **BEM Naming**
   - `.wp-block-{name}` - Block
   - `.wp-block-{name}__element` - Element
   - `.wp-block-{name}--modifier` - Modifier

3. **Accessibility**
   - Semantic HTML
   - Keyboard navigation
   - Focus states
   - Screen reader support

4. **Responsive**
   - Mobile-first CSS
   - Breakpoint: 767px

   - FSE ready
   - theme.json compatible
