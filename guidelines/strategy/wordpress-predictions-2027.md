# WordPress 2026-2027 Horizon Signals

## Release cadence signals

WordPress publishes projected major releases for 2026 (7.0, 7.1, 7.2), with feature freeze one month before release.

## Theme system maturation

theme.json v3 is the living specification and is compatible with WordPress 6.6+; tokenisation and global styles become the primary standardisation mechanism.

## Interaction model direction

Interactivity API is public for developers (as of WP 6.5) and provides a WordPress-native approach to client-side interactivity.

## Data wiring direction

Block Bindings API (WP 6.5+) enables binding dynamic data to block attributes for supported blocks, reducing bespoke glue logic.

## Implication for LightSpeed

The product is not "building pages." The product is a governed block theme system with tokens, patterns, and progressive interactivity that remains performant and editable as WordPress evolves.
