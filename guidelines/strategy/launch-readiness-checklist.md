# Launch Readiness Checklist 2026

**Category:** Strategy  
**Version:** 1.0.0  
**Last Updated:** 2026-03-15  
**Status:** Active  
**Template Used:** _templates/general-template.md

---

## Content QA

- [ ] Heading hierarchy validated (single H1, logical H2-H6)
- [ ] No generic filler copy
- [ ] All proof claims backed by measurable sources
- [ ] Systems language used consistently (not agency commodity language)

## Schema validation

- [ ] Article schema on Insights and case studies
- [ ] FAQ schema used only when eligibility and strategy justify it
- [ ] Paywalled markup used where relevant
- [ ] Organisation schema on About page

## Accessibility audit

- [ ] WCAG 2.2 alignment and evidence of testing
- [ ] EU accessibility obligations: EAA applies from June 28, 2025 for covered services
- [ ] Keyboard navigation verified on all interactive elements
- [ ] Focus management verified for modals and overlays
- [ ] Reduced motion support verified

## Performance targets

- [ ] INP targeted and monitored (< 200ms good range)
- [ ] Page weight budgets set per template type
- [ ] JS budget enforced (marketing pages minimal JS)
- [ ] Image optimisation pipeline verified
- [ ] Critical CSS extraction verified

## AI search readiness

- [ ] Pages are indexable and eligible for snippets
- [ ] Definitional pages exist for key terms
- [ ] Answer-first formatting on system pages
- [ ] OAI-Searchbot access decision documented
- [ ] Structured data baseline implemented

## Conversion tracking

- [ ] Events defined: audit request, consultation booking, scroll depths, case study clicks
- [ ] Analytics integrity verified across migration
- [ ] Mid-funnel CTA (systems audit) tracked separately from consultation

## Migration risks

- [ ] Redirect mapping for changed URLs
- [ ] Preserve canonical tags and internal links
- [ ] Validate sitemap and recrawl requests ready (Search Console)
- [ ] 301 redirects for all deprecated URLs
