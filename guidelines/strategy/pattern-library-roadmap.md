## Governance milestones

### Adopt a pattern registry
Each pattern has: intent, constraints, allowed edits, semantic rules, and test checklist.

### Pattern naming convention
`lsx-design/{category}/{pattern-name}`

### Categories
- `layout` (site header/footer)
- `hero` (page context)
- `header` (archive/listing/page headers)
- `nav` (filters, breadcrumbs, pagination, category buttons)
- `listing` (card grids)
- `content` (editorial, media, supporting sections, FAQ sections)
- `meta` (quick facts / key-value)
- `related` (related stacks)
- `cta` (single primary CTA sections)
- `state` (empty states, error messages)
- `proof` (metrics, testimonials, case study previews)
- `system` (methodology blocks, token demos, governance visuals)
