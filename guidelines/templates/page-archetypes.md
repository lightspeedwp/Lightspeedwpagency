## Overview

Defines the 5 fixed page archetypes for the LSX Design prototype. Every page must be exactly one archetype — **no hybrids**. Split into 2 focused sub-files.

---

## Sub-Files

| File | Contents | Approx Lines |
|---|---|---|
| [archetype-definitions.md](./page-archetypes/archetype-definitions.md) | Philosophy, all 5 archetypes with section orders and code examples (Content Hub, Taxonomy Archive, Single Detail, Editorial Listing, Utility Page), selection decision tree | ~205 |
| [archetype-rules.md](./page-archetypes/archetype-rules.md) | 3 archetype rules (no hybrids, empty sections, section order), pattern composition, related guidelines | ~138 |

## Quick Reference

| Archetype | Use For | WordPress Template |
|-----------|---------|-------------------|
| Content Hub | Blog, portfolio, service archives | `archive.html` |
| Taxonomy Archive | Category, tag, author pages | `category.html`, `tag.html` |
| Single Detail | Posts, projects, services | `single.html`, `page.html` |
| Editorial Listing | Blog index, news hub | `index.html`, `home.html` |
| Utility Page | 404, contact, search | `404.html`, `search.html` |
