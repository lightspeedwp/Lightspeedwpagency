## Quick Reference

| Pattern | Background Variable | Use For |
|---------|-------------------|---------|
| Default | `var(--background)` | Main content areas |
| Card (recommended) | `var(--card)` | Featured sections |
| Muted | `var(--muted)` | Alternating sections |
| Glass | `var(--glass-bg)` | Overlays, floating UI |
