# Aside Post Format

The Aside post format is for short, status-update style content without titles.

## Features
- **Stream Layout:** Displayed in a continuous feed.
- **Iconography:** Distinguishable icon (e.g., message bubble).
- **Brief:** Optimized for short text.

## WordPress Implementation
- **Post Format:** `aside`
- **Template:** `archive-aside.html` (maps to `AsideStreamTemplate`)

## Usage
Select "Aside" from the Post Format meta box.
