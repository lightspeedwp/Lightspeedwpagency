# Gallery Post Format

The Gallery post format is designed for image-heavy posts, such as event recaps or photo essays.

## Features
- **Grid/Slider View:** Displays images in a responsive grid or slider.
- **Instagram Style:** Mimics social media feeds for archives.
- **Visual Focus:** Minimal text, maximum imagery.

## WordPress Implementation
- **Post Format:** `gallery`
- **Template:** `single-gallery.html` (maps to `SingleGalleryTemplate`)
- **Archive:** `archive-gallery.html` (maps to `GalleryArchiveTemplate`)

## Data Structure
- `gallery_images`: Array of image URLs

## Usage
Select "Gallery" from the Post Format meta box.
