# WooCommerce Blocks Overview

**Purpose:** E-commerce functionality for WordPress sites

## Available Blocks

### Core Commerce
- **Product Grid** - Product listings with filters
- **Product Details** - Single product display
- **Add to Cart** - Cart button component

### Cart & Checkout
- **Cart** - Shopping cart interface
- **Checkout** - Checkout flow
- **Mini Cart** - Header cart widget

### Supporting Blocks
- **Reviews** - Product reviews display
- **Related Products** - Product recommendations
- **Upsells** - Cross-sell products
- **Filters** - Product filtering
- **Product Search** - Search widget

## Design System

All WooCommerce blocks use:
- **Base CSS:** `/src/styles/blocks/woocommerce/woo-base.css`
- **Typography:** `var(--font-primary)`
- **Spacing:** `var(--spacing-*)`
- **Colors:** CSS variables only
