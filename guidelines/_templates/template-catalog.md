## Available Templates

### 1. Design Tokens Template
**File:** `design-token-template.md`  
**Use for:** Color systems, typography, spacing, shadows, borders

**Structure:** Overview, CSS Variables, Usage Examples, WordPress Mapping, Do's/Don'ts, Related Tokens

---

### 2. Component Guidelines Template
**File:** `component-template.md`  
**Use for:** React components, WordPress blocks, patterns

**Structure:** Component Overview, Props/API Reference, CSS Classes (BEM), Usage Examples, Variants, Accessibility, WordPress Mapping, Related Components

---

### 3. General Guidelines Template
**File:** `general-template.md`  
**Use for:** Processes, standards, architectural decisions

**Structure:** Purpose, Scope, Requirements (MUST/SHOULD/MAY), Examples, Anti-patterns, Checklist, Related Guidelines

---

### 4. Report Template
**File:** `report-template.md`  
**Use for:** Audit reports, completion reports, analysis documents

**Structure:** Executive Summary, Methodology, Findings, Impact Analysis, Recommendations, Action Items, Success Criteria

---

### 5. Prompt Template
**File:** `prompt-template.md`  
**Use for:** AI prompts, orchestrator prompts, task automation

**Structure:** Prompt Purpose, Context/Background, Input Requirements, Expected Output, Success Criteria, Workflow Steps, Error Handling

---

### 6. Task List Template
**File:** `task-list-template.md`  
**Use for:** Project task tracking, implementation plans

**Structure:** Initiative Overview, Task Categories, Task Items (checkboxes), Priority Levels, Time Estimates, Dependencies, Completion Criteria

---

### 7. Documentation Template
**File:** `docs-template.md`  
**Use for:** General documentation, quick references, onboarding guides

**Structure:** Document Purpose, Audience, Prerequisites, Content Sections, Examples, FAQs, Next Steps

---

### 8. ATTRIBUTIONS Template
**File:** `ATTRIBUTIONS-template.md`  
**Use for:** Third-party libraries, tools, resources

**Structure:** Project Name, Version, License, URL, Description

---

### 9. README Template
**File:** `README-template.md`  
**Use for:** Project overview, setup instructions

**Structure:** Project Name, Description, Installation, Usage, Contributing, License

---

### 10. CHANGELOG Template
**File:** `CHANGELOG-template.md`  
**Use for:** Changes, updates, releases

**Structure:** Version, Date, Changes, Additions, Fixes, Removals

---
