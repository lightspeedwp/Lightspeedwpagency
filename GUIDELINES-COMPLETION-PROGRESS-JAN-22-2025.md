## 🎯 QUALITY STANDARDS

All guidelines must include:

✅ **Guideline File (.md)**
- Purpose and use cases
- Design system integration (typography, spacing, colors, radius)
- Component structure (TypeScript/React)
- WordPress mapping
- Accessibility requirements
- Best practices
- Usage examples

✅ **CSS File (.css)**
- BEM naming (`.wp-block-*`)
- 100% CSS variables (no hardcoded values)
- Responsive media queries
- Light/dark mode support
- Hover/focus states
- WCAG 2.1 AA compliant

✅ **Typography Compliance**
- ONLY use `var(--font-primary)` or `var(--font-secondary)`
- NEVER hardcode font names
- All sizes use `var(--text-*)`

✅ **Spacing Compliance**
- ONLY use `var(--spacing-*)`
- NEVER hardcode px values
- Use WordPress utility classes where appropriate

✅ **Color Compliance**
- ONLY use CSS variables
- NEVER hardcode hex/rgb values
- Support both light and dark modes
