## Updated Six-Stage Process

### 1. Discover

**Description:**
Research client goals, audience and technical requirements through workshops, audits and competitive analysis.

**Activities:**
- Stakeholder interviews
- Content audit and migration scoping
- Technical architecture review
- Competitor analysis
- User research and personas
- SEO/AEO baseline audit

**AI Enhancements:**
- AI feasibility analysis (can AI help achieve goals?)
- Automated content audits (structure, gaps, opportunities)
- Migration scope planning with AI data mapping
- Competitive AI visibility analysis
- Predictive traffic modeling

**Deliverables:**
- Discovery report
- Technical specification
- Migration plan (if applicable)
- AI opportunity assessment
- Project roadmap

**Duration:** 1–2 weeks

**Client involvement:** High (workshops, interviews, data access)

---

### 2. Create

**Description:**
Develop wireframes, design systems, prototypes and content libraries using AI-assisted tools.

**Activities:**
- Information architecture
- Wireframing and prototyping
- Design system development
- Content strategy and templates
- Accessibility planning
- Brand integration

**AI Enhancements:**
- AI-assisted copywriting and content generation
- Design token generation from brand guidelines
- Automated accessibility testing (colour contrast, hierarchy)
- AI layout suggestions based on user behavior data
- Prototype testing with AI user simulation

**Deliverables:**
- Wireframes and prototypes
- Design system (tokens, components, patterns)
- Content templates and guidelines
- Accessibility audit and plan
- Interactive Figma prototypes

**Duration:** 2–4 weeks

**Client involvement:** Medium (design reviews, content workshops)

---

### 3. Build

**Description:**
Code custom block themes, integrate APIs, migrate content and build features using modern WordPress standards.

**Activities:**
- Custom block theme development
- Plugin and integration development
- Content migration
- API integrations (CRM, analytics, e-commerce)
- Performance optimization
- Security hardening

**AI Enhancements:**
- AI-generated boilerplate code (blocks, patterns, templates)
- Code review bots (standards compliance, security)
- Automated regression testing
- AI-assisted migration (content mapping, redirect planning)
- Performance profiling with AI recommendations

**Deliverables:**
- Custom block theme codebase
- Custom plugins and integrations
- Migrated content (if applicable)
- Testing reports
- Documentation
- GitHub repository access

**Duration:** 4–8 weeks

**Client involvement:** Low (demos, feedback, UAT)

---

### 4. Launch

**Description:**
Prepare production environment, run comprehensive QA, train stakeholders and deploy to live.

**Activities:**
- Production environment setup
- Comprehensive QA (functional, accessibility, performance)
- Content review and final edits
- Stakeholder training
- DNS and domain migration
- Go-live deployment

**AI Enhancements:**
- AI-guided QA checklists (nothing missed)
- Performance benchmarking and optimization
- AI-generated training materials and documentation
- Automated post-launch monitoring
- AI search engine submission and indexing verification

**Deliverables:**
- Live website
- QA and accessibility reports
- Training documentation and videos
- Performance reports (Core Web Vitals)
- Launch checklist (completed)

**Duration:** 1–2 weeks

**Client involvement:** High (training, final approvals, content review)

---

### 5. Grow

**Description:**
Optimise performance, SEO/AEO, accessibility and maintain the site for continuous improvement.

**Activities:**
- Performance monitoring and optimization
- SEO/AEO ongoing optimization
- Accessibility audits and improvements
- Security updates and patches
- Content optimization
- Analytics and reporting

**AI Enhancements:**
- AI-driven analytics (traffic patterns, user behavior)
- Core Web Vitals optimization with AI recommendations
- Answer engine optimization (AEO)
- AI content suggestions based on search trends
- Predictive maintenance (detect issues before they occur)
- Automated uptime and security monitoring

**Deliverables:**
- Monthly performance reports
- SEO/AEO dashboards
- Security and uptime reports
- Content recommendations
- Optimization action plans

**Duration:** Ongoing (monthly retainer)

**Client involvement:** Medium (review reports, approve optimizations)

---

### 6. Evolve

**Description:**
Integrate new AI tools, monitor AI visibility, adapt to future trends and continuously improve.

**Activities:**
- AI feature integration
- AI search visibility monitoring
- Predictive analytics and trend forecasting
- AI cost optimization
- Strategic planning and roadmap updates
- Experimentation with emerging AI tools

**AI Enhancements:**
- AI visibility tracking (ChatGPT, Perplexity, Gemini citations)
- Predictive analytics (forecast traffic, conversions, issues)
- AI cost-benefit analysis (what's working, what's not)
- AI governance and ethical AI audits
- Strategy updates based on AI trends

**Deliverables:**
- Quarterly AI visibility reports
- Predictive analytics dashboards
- AI cost optimization plans
- Strategic roadmap updates
- Experimentation findings and recommendations

**Duration:** Ongoing (quarterly reviews)

**Client involvement:** Low (strategic reviews, roadmap approval)

## WebGL & Interactive Ideas

### 1. Interactive Process Diagram

**Concept:**
Circular or linear diagram where each stage is a glowing node connected by animated lines.

**Implementation:**
- Circular layout shows cyclical nature (Evolve → Discover)
- Nodes glow with stage-specific colors:
  - Discover: neon-cyan
  - Create: neon-pink
  - Build: neon-lime
  - Launch: neon-yellow
  - Grow: neon-purple
  - Evolve: gradient (all colors)
- Hover over node expands to show description and AI enhancements
- Lines animate with particles flowing through the cycle
- Click node to scroll to detailed section

**Interaction:**
- Auto-rotate through stages on page load
- Hover pauses rotation, expands node
- Click jumps to detailed section below
- Mobile: tap to expand, swipe to rotate

### 2. Process Navigator

**Concept:**
Vertical stepper in sidebar that updates as users scroll through process stages.

**Implementation:**
- Fixed sidebar on desktop
- Shows current stage highlighted
- Progress bar fills as user scrolls
- Clicking stage scrolls to that section
- Mini-icons represent each stage

**Interaction:**
- Automatically highlights as user scrolls
- Click to jump to stage
- Mobile: horizontal stepper at top
- Accessibility: skip links to each stage

### 3. Animated AI Overlay

**Concept:**
Subtle WebGL particles flowing through process diagram representing data and AI.

**Implementation:**
- Particles flow from stage to stage
- Speed increases during Build and Grow
- Color matches stage accent
- Intensity visualizes AI contribution (more particles = more AI)
- Respects reduced motion preference

**Interaction:**
- Passive animation (no direct interaction)
- Pauses when user hovers over node
- Resumes on mouse leave
- Disabled on low-end devices

## Design System Requirements

### Typography
- Headings: `var(--font-primary)` (Lexend) — sentence case

  - Discover: `var(--wp--preset--color--neon-cyan)`
  - Create: `var(--wp--preset--color--neon-pink)`
