## WebGL & Interactive Ideas

### 1. Design System Collage (Hero)

**Concept:**
3D rotating collage of UI components orbiting a central axis, demonstrating design system depth.

**Implementation:**
- WebGL canvas with floating UI elements:
  - Buttons (various states)
  - Cards (glassmorphism)
  - Typography specimens
  - Form inputs
  - Navigation menus
  - Icons with neon glow
- Elements orbit central axis in 3D space
- Neon-cyan and neon-pink accents
- User cursor influences rotation speed and direction
- Elements scale larger as they rotate to front
- Click element to freeze rotation and show specifications

**Interaction:**
- Desktop: mouse movement controls rotation
- Mobile: device tilt or touch-drag
- Hover element: pause rotation, show tooltip with component name
- Click: open component spec modal with code sample

**Visual details:**
- Dark space background with particle stars
- Components have subtle neon outlines
- Depth of field blur (distant elements softer)
- Smooth easing on all movements

### 2. Design Process Visualizer

**Concept:**
Interactive journey through the design process with expanding detail panels.

**Implementation:**
- Vertical timeline with six process stages
- Each stage represented by large neon node
- As user scrolls, current stage lights up and expands
- Expanded view shows:
  - Stage description
  - Activities and deliverables
  - Sample work (wireframes, mockups, prototypes)
  - AI enhancements for that stage
- Particles flow down the timeline
- Progress indicator on sidebar

**Animation sequence:**
1. User scrolls to process section
2. Timeline fades in with stagger effect
3. Nodes appear one-by-one with pulse
4. Connecting line draws with particle trail
5. First stage auto-expands
6. User can scroll or click to navigate

**Interaction:**
- Scroll to progress through stages
- Click stage node to jump directly
- Keyboard arrows to navigate
- Mobile: swipe between stages

### 3. Portfolio Case Study Carousel

**Concept:**
3D carousel of project cards that flip to reveal details and metrics.

**Implementation:**
- Carousel of 6-8 project cards arranged in semi-circle
- Card fronts: hero image with neon frame
- Card backs: project details, metrics, testimonial quote
- Drag carousel to rotate
- Click card to flip
- Selected card centers and enlarges
- "View full case study" button appears

**Card structure:**

**Front:**
- Project hero image
- Neon frame (color matches project aesthetic)
- Project name overlay
- Client logo
- Hover: subtle scale and glow

**Back:**
- Project title and client
- Quick description (50 words)

## Design System Requirements

### Typography

- **Headings:** `var(--font-primary)` (Lexend) — sentence case
- **Body:** `var(--font-secondary)` (Manrope)
- **Package names:** Bold, large, uppercase
- **Component labels:** Small, uppercase, wide letter-spacing

### Colours (Funky Neon)

**Dark mode:**
- Background: `var(--color-black)`
- Process stages:
  - Discovery: `var(--wp--preset--color--neon-cyan)`
  - Wireframing: `var(--wp--preset--color--neon-pink)`
  - Design Systems: `var(--wp--preset--color--neon-lime)`
  - Visual Design: `var(--wp--preset--color--neon-yellow)`
  - Prototyping: `var(--wp--preset--color--deep-purple)`
  - AI Integration: gradient (all colors)
- Cards: glassmorphism with neon borders
- Hover states: neon glow

**Light mode:**
- Professional clean aesthetic
- Neon as accent colors only
- Blue primary color

### Spacing

- Section padding: `var(--spacing-24)` desktop, `var(--spacing-16)` mobile
- Component explorer gaps: `var(--spacing-6)`
- Portfolio card gaps: `var(--spacing-8)`
- Timeline spacing: `var(--spacing-16)` between stages

### Components

**Use existing:**
