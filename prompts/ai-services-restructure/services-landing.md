## Purpose

Redesign the Services landing page with a Funky neon aesthetic that introduces LightSpeed's system-centric approach to WordPress. Transform the static, siloed service cards into a cohesive, interactive journey through the lifecycle model (Discover → Create → Build → Launch → Grow → Evolve) while showcasing three package tiers and all service offerings with neon accents and WebGL visualizations.

---

## Summary

**Value** — The services landing page introduces LightSpeed's system-centric approach to WordPress. It highlights three package tiers (Foundation, Growth, Enterprise) and emphasizes performance, accessibility, AI search readiness and scalable architecture.

**Risks** — The content feels siloed, with separate cards for AI, content and design services rather than a cohesive journey. The static hero lacks the sense of scale and integration that LightSpeed offers. Without interactive storytelling and the Funky neon aesthetic, visitors may not appreciate the full breadth of capabilities.

**Next step** — Reframe the page around the lifecycle model with Funky neon WebGL visualizations, unifying service categories into an integrated experience that showcases the neon aesthetic throughout.

## WebGL & Interactive Ideas

### 1. Systems Assembly Hero

**Concept:**
3D scene of modular blocks snapping together to form three vertical columns representing service tiers.

**Implementation:**
- Three columns rise from bottom as user scrolls into view
- Each column assembles from glowing neon blocks:
  - **Foundation:** 6 blocks (cyan glow)
  - **Growth:** 10 blocks (pink glow)
  - **Enterprise:** 15 blocks (lime glow)
- Blocks represent service modules:
  - Design systems layer (pink)
  - Development layer (lime)
  - AI tools layer (cyan)
  - Hosting layer (purple)
  - Performance layer (yellow)
  - Training layer (orange)
- Hover over block reveals tooltip with service name
- Click block to navigate to service detail page
- Particles flow upward showing data/energy

**Animation sequence:**
1. Foundation column assembles (2s)
2. Growth column assembles (2.5s)
3. Enterprise column assembles (3s)
4. Particles begin flowing
5. User can interact

**Interaction:**
- Desktop: hover blocks for tooltips, click to navigate
- Mobile: tap blocks, swipe between columns
- Auto-rotate camera slowly
- Accessibility: Static tier comparison table toggle

### 2. Lifecycle Journey Carousel

**Concept:**
Horizontal timeline with six stages, each revealing associated services when activated.

**Implementation:**
- Six large stage nodes in a line
- Current stage highlighted with neon glow
- Inactive stages dimmed but visible
- Click/tap stage to activate:
  - Stage node pulses with color
  - Service cards slide up from below
  - Particle burst animation
  - Other stages dim
- Services grouped by stage:
  - **Discover:** Strategy, Audits, Research
  - **Create:** Design, Content, Prototyping
  - **Build:** Development, Migration, Integration
  - **Launch:** QA, Training, Deployment
  - **Grow:** SEO/AEO, Performance, Support
  - **Evolve:** AI Integration, Analytics, Innovation

**Visual treatment:**
- Stage nodes: 3D spheres with inner glow
- Connection lines with animated particles
- Service cards: glassmorphism with neon borders
- Color-coded by stage
- Smooth transitions between stages

**Interaction:**
- Click stage to expand services
- Arrow keys or swipe to navigate stages
- Auto-advance every 5s when idle
- Progress bar shows position in journey

### 3. Service Matrix Explorer

**Concept:**
Interactive grid showing all services organized by lifecycle stage (rows) and service type (columns).

**Implementation:**
- Rows: 6 lifecycle stages
- Columns: Design, Development, AI, Performance, Training, Support
- Cells: service offerings (glowing dots or icons)
- Hover cell to see service name and description
- Click to navigate to service page
- Filter by:
  - Service type (show only Design services)
  - Lifecycle stage (show only Build phase)
  - Package tier (show only Enterprise services)

**Visual design:**
- Dark grid with neon gridlines
- Cells glow on hover with stage color
- Active filters highlighted with neon borders
- Legend shows color mapping
- Responsive: stack on mobile

**Interaction:**
- Hover highlights row and column
- Click cell opens service detail
- Filter buttons toggle with neon active state
- Export matrix as PDF (optional)

## Design System Requirements

### Typography

- **Headings:** `var(--font-primary)` (Lexend) — sentence case, never title case
- **Body:** `var(--font-secondary)` (Manrope)
- **Badges:** Uppercase, `var(--letter-spacing-wide)`
- **Package names:** Bold, large, Lexend

### Colours (Funky Neon Palette)

**Dark mode (primary experience):**
- Background: `var(--color-black)` or `var(--color-gray-900)`
- Stage colors:
  - Discover: `var(--wp--preset--color--neon-cyan)`
  - Create: `var(--wp--preset--color--neon-pink)`
  - Build: `var(--wp--preset--color--neon-lime)`
  - Launch: `var(--wp--preset--color--neon-yellow)`
  - Grow: `var(--wp--preset--color--deep-purple)`
  - Evolve: gradient (all neon colors)
- Accents: neon glows, borders, particles
- Cards: glassmorphism with `rgba(255, 255, 255, 0.05)` + neon borders

**Light mode:**
- Background: `var(--color-white)` or `var(--color-gray-50)`
- Neon colors as accents only (borders, badges, icons)
- Professional blue for primary elements
- Clean, minimal aesthetic

**IMPORTANT:** Neon foreground colors (text/icons) ONLY on dark backgrounds. Never neon text on light surfaces.

### Spacing

- Section padding: `var(--spacing-24)` desktop, `var(--spacing-16)` mobile
- Card gaps: `var(--spacing-8)`, `var(--spacing-6)`, `var(--spacing-4)`
- Container max-width: `var(--max-w-7xl)`
- Hero min-height: `80vh`

### Service Catalog Data Structure

```typescript
interface ServicePackage {
  id: 'foundation' | 'growth' | 'enterprise';
  name: string;
  tagline: string;
  description: string;
  color: string; // CSS variable for neon color
  pricing: {
    starting: number;
    range: string; // "$10k-25k"
  };
  services: string[]; // service IDs
  features: string[];
  bestFor: string[];
  popular?: boolean;
}

interface Service {
  id: string;
  name: string;
  category: 'design' | 'development' | 'ai' | 'performance' | 'training' | 'support';
  stages: LifecycleStage[]; // which stages include this service
  description: string;
  icon: string; // Phosphor icon name
  link: string; // detail page URL
  packages: ('foundation' | 'growth' | 'enterprise')[];
}

type LifecycleStage = 'discover' | 'create' | 'build' | 'launch' | 'grow' | 'evolve';
```
